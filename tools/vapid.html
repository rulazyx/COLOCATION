🔑 Clés VAPID

Ces 2 clés autorisent ton serveur à envoyer des notifications. Elles sont générées dans ton navigateur, rien n'est envoyé nulle part.

Clé publique → à coller dans config.js (VAPID_PUBLIC_KEY) et dans les secrets Supabase (VAPID_PUBLIC_KEY)

Clé privée → à coller UNIQUEMENT dans les secrets Supabase (VAPID_PRIVATE_KEY)

⚠️ Ne mets jamais la clé privée dans GitHub ni dans config.js. Une fois les clés copiées, tu peux supprimer ce fichier du dépôt.
